# 第 14 课：综合项目最终验收

本课不额外提供脚本。请使用前面三个综合项目和自己的测试材料完成验收。

## 必做项目

### A：二进制文件分析器

- 只读打开文件；
- 输出大小和头部十六进制；
- 至少识别两种签名；
- 对空文件、短文件、不存在文件做测试。

### B：命令行通讯录

- 添加、查找和列出联系人；
- 检查容量和字符串长度；
- 正确处理空行、过长输入和不存在联系人；
- 为每个命令设计返回值。

### C：文本日志分析器

- 逐行读取文件；
- 统计 INFO、WARN、ERROR；
- 报告无法识别行和读取错误；
- 测试无换行结尾和超长行。

## 调试与测试验收

- [ ] 编译时没有未解释的警告。
- [ ] 用调试器观察过至少一个函数调用栈。
- [ ] 用 ASan 检查过一个边界错误。
- [ ] 用 UBSan 检查过一个未定义行为。
- [ ] 写过至少三个自动化测试。
- [ ] 有一个最小输入和最小复现记录。
- [ ] 测试覆盖正常、边界和错误输入。
- [ ] 综合项目能从干净目录重新构建。
- [ ] README 写清构建、运行、测试和限制。

## 推荐最终命令

```sh
gcc -std=c17 -Wall -Wextra -Wconversion -pedantic -g -O0 \
    practice.c -o practice
./practice
```

如果项目是多文件的，README 中必须列出所有源文件、头文件搜索路径和构建顺序。
