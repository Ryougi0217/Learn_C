# 第 2 课：调试器断点

## 学习目标

编译调试版本并在函数入口、循环和条件分支设置断点。

## 核心概念

- 调试构建通常保留符号并关闭过度优化，例如使用 `-g -O0`。
- 断点让程序在指定位置暂停。
- 断点应放在状态即将变化或错误已经可疑的位置。
- 调试器观察的是程序实际执行路径，不是猜测的路径。

## 完整示例

先阅读并运行下面的完整示例，再打开同目录的 `practice.c` 手写关键部分。

```c
#include <stdio.h>

int main(void)
{
    int total = 0;

    for (int i = 1; i <= 5; i++) {
        total += i;
        printf("i=%d total=%d\n", i, total);
    }

    return 0;
}
```

## 练习任务

1. 编译调试版本：
```sh
gcc -std=c17 -Wall -Wextra -g -O0 practice.c -o practice
```
2. 在循环体设置断点，观察 `i` 和 `total`。
3. 在 `total += i` 前后分别暂停。
4. 记录程序实际执行了多少轮。
