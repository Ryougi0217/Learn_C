# 附录第 3 课：未初始化指针

## 学习目标

区分未初始化指针、空指针和有效指针，避免在没有目标对象时解引用。

## 核心概念

- 未初始化自动变量的值不确定。
- `NULL` 是明确的空指针值，但它也不能被解引用。
- 指针安全需要“指向有效对象”而不仅仅是“有一个地址”。
- 编译器警告和 Sanitizer 都可能帮助发现未初始化使用。

## 完整示例

先阅读并运行默认安全路径，再打开同目录的 `practice.c` 完成练习。带宏的危险路径只用于诊断。

```c
#include <stdio.h>

int main(void)
{
    int value = 42;
    int *pointer = &value;

    printf("%d\n", *pointer);
    return 0;
}
```

## 练习任务

1. 让 `practice.c` 的指针先指向一个真正的整数。
2. 分别说明未初始化指针和 `NULL` 指针的区别。
3. 使用严格警告编译，记录未初始化分支的提示。
4. 解释为什么给指针随便填一个整数也不是初始化。
