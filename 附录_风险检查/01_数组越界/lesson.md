# 附录第 1 课：数组越界

## 学习目标

识别下标越过数组有效范围的代码，并用边界条件保证每次访问合法。

## 核心概念

- 长度为 `count` 的数组合法下标是 `0` 到 `count - 1`。
- 循环条件应写成 `i < count`。
- 越界读取和越界写入都属于未定义行为。
- ASan 可以帮助定位实际越界行。

## 完整示例

先阅读并运行默认安全路径，再打开同目录的 `practice.c` 完成练习。带宏的危险路径只用于诊断。

```c
#include <stdio.h>

int main(void)
{
    int values[3] = {10, 20, 30};

#if defined(OOB_DEMO)
    printf("%d\n", values[3]);  /* 诊断用越界 */
#else
    printf("%d\n", values[2]);
#endif

    return 0;
}
```

## 练习任务

1. 默认编译运行安全分支。
2. 用 `-DOOB_DEMO -fsanitize=address` 编译诊断分支。
3. 把所有循环边界改成半开区间。
4. 说明为什么 `values[3]` 即使偶尔打印出数字也不正确。
