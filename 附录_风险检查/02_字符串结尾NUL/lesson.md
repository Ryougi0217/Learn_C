# 附录第 2 课：字符串结尾 \0

## 学习目标

确认 C 字符串必须有 NUL 终止符，并避免把普通字符数组误当作字符串。

## 核心概念

- `strlen`、`printf("%s")` 等字符串函数依赖 `\0`。
- 字符数组容量必须包含终止符所需的空间。
- 没有终止符时，函数会继续读取数组之外的内存。
- 二进制缓冲区不应直接交给字符串函数。

## 完整示例

先阅读并运行默认安全路径，再打开同目录的 `practice.c` 完成练习。带宏的危险路径只用于诊断。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char word[4] = {'c', 'a', 't', '\0'};

    printf("%s length=%zu\n", word, strlen(word));
    return 0;
}
```

## 练习任务

1. 在 `practice.c` 中补齐字符串末尾的 `\0`。
2. 把数组容量改成 `3`，解释为什么不够保存字符串。
3. 使用 `fwrite` 输出可能包含 `\0` 的字节数组。
4. 用 Sanitizer 观察没有终止符时的风险。
