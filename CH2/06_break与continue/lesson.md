# 第 6 课：`break` 与 `continue`

## 本课目标

完成本课后，你应该能够：

- 使用 `break` 立即结束最近的一层循环；
- 使用 `continue` 跳过当前迭代的剩余部分；
- 说明 `continue` 在 `for` 和 `while` 中如何继续推进；
- 避免用控制跳转掩盖错误的循环条件。

## 1. `break`

`break` 结束它所在的最近一层 `for`、`while`、`do while` 或 `switch`，执行流跳到该结构之后。它不是结束整个程序，也不是跳出所有嵌套循环。

常见用途是“找到目标后停止搜索”或“遇到终止标记后结束处理”。

## 2. `continue`

`continue` 放弃本轮循环剩余语句，直接开始下一轮判断：

- 在 `for` 中，先执行更新部分，再重新判断条件；
- 在 `while`/`do while` 中，直接回到条件判断位置。

因此在 `while` 中使用 `continue` 时，必须保证状态更新不会被跳过，否则可能出现无限循环。

## 3. 控制流要可解释

`break` 和 `continue` 可以让代码更清晰，也可能让控制流分散。使用它们时要写出停止条件或跳过条件；如果一个循环包含很多跳转，考虑是否应该重新整理循环结构。

## 4. 完整示例

这个示例会在遇到 8 时停止循环，并跳过偶数：

```c
#include <stdio.h>

int main(void)
{
    int stop_at = 8;

    for (int i = 1; i <= 10; i++) {
        if (i == stop_at) {
            break;
        }

        if (i % 2 == 0) {
            continue;
        }

        printf("接受：%d\n", i);
    }

    printf("循环结束。\n");
    return 0;
}
```

预期只会打印 1、3、5、7。把 `break` 或 `continue` 暂时注释掉，再预测输出如何变化。
