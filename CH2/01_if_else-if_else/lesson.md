# 第 1 课：`if`、`else if` 与 `else`

## 本课目标

完成本课后，你应该能够：

- 使用条件表达式选择不同执行路径；
- 解释 C 中“零为假、非零为真”的规则；
- 写出互斥的 `if`/`else if`/`else` 分支；
- 通过边界值测试发现条件遗漏或顺序错误。

## 1. 条件表达式

`if` 后面的括号中放一个表达式：

```c
if (score >= 60) {
    printf("通过\n");
}
```

表达式结果为 `0` 时条件为假，结果为非零值时条件为真。比较表达式通常产生 `0` 或 `1`，但写条件时也可以直接使用其他整数表达式。

建议始终使用花括号，即使分支当前只有一条语句。这样在以后添加语句时不容易出现“看起来属于分支、实际不属于分支”的错误。

## 2. 多路选择

`else if` 用于继续检查其他条件，`else` 处理前面条件都不满足的情况：

```c
if (score >= 90) {
    /* A */
} else if (score >= 60) {
    /* B */
} else {
    /* 不及格 */
}
```

从上到下检查，执行第一个为真的分支，然后跳过同一组中的其余分支。因此条件顺序很重要：更严格的上界/下界判断应放在合适的位置。

## 3. 常见陷阱

- 把相等比较 `==` 写成赋值 `=`；
- 忘记边界，例如没有决定 `score == 60` 属于哪一类；
- 使用多个独立 `if` 却以为它们互斥；
- 省略花括号导致缩进和实际控制流不一致。
