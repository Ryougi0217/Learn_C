# 第 10 课：递归基础

## 本课目标

完成本课后，你应该能够：

- 识别递归函数的终止条件；
- 写出能逐步接近终止条件的递归调用；
- 说明递归调用如何占用调用栈；
- 用小输入验证递归结果和调用过程。

## 1. 递归的两个部分

递归函数会调用自己，但必须同时具备：

1. 基础情况（base case）：达到它时不再递归；
2. 递归情况：把问题变成更小或更接近基础情况的版本。

例如计算 `1 + 2 + ... + n`：

```c
int sum_to(int n)
{
    if (n <= 0) {
        return 0;
    }
    return n + sum_to(n - 1);
}
```

`n` 每次减少 1，最终会到达 `n <= 0`。如果没有基础情况，或者参数没有向基础情况推进，就会无限递归，最终耗尽调用栈。

## 2. 调用栈直觉

调用 `sum_to(3)` 时，大致会形成：

```text
sum_to(3)
  └─ sum_to(2)
       └─ sum_to(1)
            └─ sum_to(0)
```

最深层先返回，上一层再把自己的 `n` 加上去。递归深度太大可能消耗很多栈空间，因此实际项目中要根据问题规模选择递归或循环。
