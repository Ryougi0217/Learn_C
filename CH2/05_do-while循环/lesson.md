# 第 5 课：`do while` 循环

## 本课目标

完成本课后，你应该能够：

- 解释 `do while` 和 `while` 的执行顺序差异；
- 写出至少执行一次的循环；
- 识别条件末尾的分号；
- 选择适合“先做一次，再决定是否继续”的结构。

## 1. 先执行再判断

`do while` 的结构是：

```c
do {
    /* 至少执行一次 */
} while (condition);
```

注意条件末尾的分号。无论初始条件是否为真，循环体都会先执行一次；之后才判断是否继续。

这适合菜单展示、至少读取一次输入、先完成一次尝试再判断是否重试等场景。若任务允许一次都不执行，则应考虑 `while`。

## 2. 控制循环次数

循环体中仍然需要更新状态。下面的流程是“打印一次、增加次数、判断是否达到上限”：

```c
int count = 0;
do {
    count++;
} while (count < limit);
```

当 `limit` 为 `0` 时，循环仍会执行一次；这正是它和 `while` 的观察重点。

2. 记录每个值实际执行了几次；

4. 将脚本改写成 `while`，比较 `limit = 0` 时的行为；
5. 检查并解释 `while (condition);` 末尾分号的作用。
