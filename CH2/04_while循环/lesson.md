# 第 4 课：`while` 循环

## 本课目标

完成本课后，你应该能够：

- 解释 `while` 是先判断、后执行；
- 为循环设计会变化的状态；
- 用循环处理“不确定重复次数”的任务；
- 发现并避免条件永远不变造成的无限循环。

## 1. 先判断再执行

`while` 的结构是：

```c
while (condition) {
    /* 可能执行零次或多次 */
}
```

每次进入循环体前都会检查条件。若初始条件为假，循环体不会执行。适合在“只要条件成立就继续”的场景中使用，例如处理剩余数量、读取直到结束标记等。

## 2. 循环必须向终止条件前进

循环体中通常要修改参与条件判断的状态：

```c
int remaining = 3;
while (remaining > 0) {
    printf("%d\n", remaining);
    remaining--;
}
```

如果 `remaining` 从未改变，或者改变方向让它永远满足条件，程序就可能无法结束。编写循环前先回答：“什么变量表示进度？每轮如何推进？什么情况下停止？”

## 3. 和 `for` 的选择

已知初始化、条件和更新都很紧凑时，`for` 常更清晰；只有条件和循环体比较重要、重复次数依赖运行状态时，`while` 常更自然。两者都能表达很多相同逻辑，优先选择更容易检查的写法。

## 填空任务

1. 修改 `remaining`，预测输出行数；
2. 把初始值改成 `0`，观察循环是否执行；
3. 将递减改成另一种推进方式，但保证最终结束；
4. 故意注释掉状态更新，说明为什么程序会卡住，然后恢复；
5. 把本练习改写成等价的 `for` 循环。
