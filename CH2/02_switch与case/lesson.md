# 第 2 课：`switch` 与 `case`

## 本课目标

完成本课后，你应该能够：

- 使用 `switch` 对整数或枚举值进行多路选择；
- 理解 `case` 标签、`break` 和 `default` 的作用；
- 识别忘记 `break` 造成的贯穿（fall-through）；
- 判断什么时候 `if` 比 `switch` 更适合。

## 1. `switch` 的结构

基本形式：

```c
switch (option) {
case 1:
    printf("查看\n");
    break;
case 2:
    printf("退出\n");
    break;
default:
    printf("未知选项\n");
    break;
}
```

`switch` 表达式通常是整数类型或枚举类型。`case` 后面需要编译期可确定的常量，并且同一个 `switch` 中不能重复使用相同标签。

## 2. `break` 和贯穿

执行匹配的 `case` 后，程序会继续向下执行，直到遇到 `break` 或整个 `switch` 结束。忘记 `break` 可能让一个选项执行多个分支，这叫贯穿。

贯穿有时可以故意使用，例如多个选项共享同一处理逻辑；这时应写注释说明意图。初学阶段先把每个独立分支的 `break` 写完整。

`default` 处理没有任何 `case` 匹配的情况。即使你认为输入一定合法，也建议保留默认分支。

## 3. 和 `if` 的选择

当判断的是离散的固定选项，`switch` 通常更直观；当条件包含范围比较、复杂逻辑或多个变量，`if` 链通常更合适。
