# 第 8 课：函数参数与返回值

## 本课目标

完成本课后，你应该能够：

- 使用参数把数据传入函数；
- 使用返回值把一个结果交回调用者；
- 理解 C 默认的按值传递；
- 识别函数输入、处理和输出的边界。

## 1. 参数是函数的输入

参数是函数接口的一部分：

```c
int add(int left, int right)
{
    return left + right;
}
```

调用时传入的表达式会得到值，函数参数接收这些值。参数名只在函数体内部有效；调用者的变量名不需要和参数名相同。

## 2. 返回值是函数的结果

`return` 把一个表达式的结果交回调用者：

```c
int total = add(3, 4);
```

函数返回后，调用者可以保存、打印或继续计算这个结果。一个函数可以有多个参数，但一次调用只能通过返回值直接交回一个结果；需要修改调用者对象或交回多个结果时，要等后续指针课程学习地址参数。

## 3. C 的按值传递

C 默认把实参的值复制给形参。函数内部修改形参，不会直接改变调用者的普通变量：

```c
void try_change(int value)
{
    value = 99;
}
```

如果要让函数修改调用者的数据，需要传递地址并使用指针。当前课程先明确“普通参数是值的副本”，避免把参数名误认为共享变量。
