# 第 12 课：基础算法练习

## 本课目标

完成本课后，你应该能够：

- 把问题拆成输入、处理和输出；
- 用循环维护累加器或计数器；
- 为算法补充边界条件；
- 用小规模样例、空范围和单元素样例验证结果；
- 对简单算法给出基本的时间复杂度判断。

## 1. 先写规则，再写代码

算法不是“想到什么写什么”。开始前先明确：

1. 输入是什么；
2. 输出是什么；
3. 初始状态是什么；
4. 每一轮如何更新；
5. 什么时候停止；
6. 空输入或最小输入的结果是什么。

例如计算 `1` 到 `n` 的总和，累加器初始为 `0`，每轮把当前数字加进去，循环结束后返回累加器。

## 2. 本课三个练习

脚本包含三个小算法：

- 求 `1` 到 `n` 的和；
- 统计 `1` 到 `n` 中能被某个除数整除的数；
- 判断一个小整数是否为素数。

它们都用循环逐个检查候选值。对于输入规模为 `n` 的版本，主要循环通常是 O(n)；复杂度是对增长趋势的描述，不是某一次运行的秒数。

## 3. 测试边界

至少测试：

- `n = 0`；
- `n = 1`；
- 一个普通的小数值；
- 素数、合数、`0` 和 `1`；
- 除数为正数的情况。

本课脚本不处理极大的整数溢出，也不接受除数为零作为合法输入。遇到不在题目约束内的输入，应先记录假设，而不是默默给出貌似正确的答案。

## 4. 完整示例

下面先看三个函数的一种完整写法，再打开 `practice.c` 自己重写：

```c
#include <stdio.h>

int sum_to(int n)
{
    int sum = 0;

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    return sum;
}

int count_multiples(int n, int divisor)
{
    int count = 0;

    for (int i = 1; i <= n; i++) {
        if (i % divisor == 0) {
            count++;
        }
    }

    return count;
}

int is_prime(int n)
{
    if (n < 2) {
        return 0;
    }

    for (int divisor = 2; divisor * divisor <= n; divisor++) {
        if (n % divisor == 0) {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    printf("sum_to(12) = %d\n", sum_to(12));
    printf("倍数数量 = %d\n", count_multiples(12, 3));
    printf("13 is %s\n", is_prime(13) ? "prime" : "not prime");

    return 0;
}
```

这是参考实现，不是本课唯一写法。你需要理解每个初值、条件和返回值，再在练习脚本中手写出来。
