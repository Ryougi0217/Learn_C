# 第 9 课：局部变量、全局变量与作用域

## 本课目标

完成本课后，你应该能够：

- 区分文件作用域、函数参数作用域和块作用域；
- 说明局部变量与全局变量的基本生命周期；
- 识别同名变量遮蔽（shadowing）；
- 了解为什么应谨慎使用全局可写状态。

## 1. 作用域和生命周期不是一回事

作用域回答“代码的哪一部分可以通过这个名字找到对象”；生命周期回答“对象从什么时候存在到什么时候结束”。

- 函数内部声明的局部变量通常只在所在函数或代码块内可见；
- 函数参数从函数体开始到函数结束可见；
- 文件外层声明的全局对象通常具有文件作用域，并在整个程序运行期间存在。

一个对象可能仍然存在，但当前代码位置已经不能通过原名字访问它。

## 2. 块作用域和遮蔽

```c
int value = 1;
{
    int value = 2;
    printf("%d\n", value);  // 使用内层 value
}
printf("%d\n", value);      // 使用外层 value
```

内层同名变量会遮蔽外层名字。遮蔽不会改变外层对象，但会增加阅读和调试成本，初学阶段尽量使用不同的、有意义的名字。

## 3. 全局变量的取舍

全局变量方便多个函数共享状态，但任何函数都可能修改它，导致调用关系和测试变复杂。优先通过参数和返回值传递数据；确实需要共享的状态要命名清楚，并限制修改位置。

本课脚本只用一个全局计数器演示生命周期，不把“能访问”当成“应该到处访问”。
