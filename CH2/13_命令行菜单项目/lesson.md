# 第 13 课：章节项目——命令行菜单程序

## 项目目标

编写一个持续运行的命令行菜单程序，综合使用：

- `do while` 或 `while`；
- `switch`、`case`、`break` 和 `default`；
- 函数声明、参数和返回值；
- `scanf` 返回值检查；
- 清晰的退出状态和错误提示。

## 1. 菜单行为

建议实现以下菜单：

```text
1. 显示问候
2. 计算 1 到 n 的总和
3. 显示循环练习提示
0. 退出
```

程序应至少显示一次菜单；选择 `0` 后正常退出；未知选项给出提示并继续显示菜单；输入不是整数时不能把未确认的值当成选项使用。

本项目采用一个明确的简化约束：遇到无法解析为整数的输入时，打印错误并返回非零状态退出。这样可以避免在还没有系统学习输入流清理前，写出可能反复读取同一个坏字符的循环。

## 2. 推荐拆分

可以使用这些函数：

- `show_menu`：只负责打印菜单；
- `print_greeting`：只负责问候；
- `sum_to`：接收 `n` 并返回总和；
- `run_sum_demo`：读取 `n`、检查输入并打印结果。

`main` 负责循环和菜单分派，不要把所有功能都塞进一个巨大函数。

## 3. 测试矩阵

至少测试：

| 输入 | 预期 |
| --- | --- |
| `1` | 执行问候功能，然后回到菜单 |
| `2` 后输入正整数 | 输出正确总和，然后回到菜单 |
| `3` | 显示提示，然后回到菜单 |
| 未知整数 | 输出未知选项，然后回到菜单 |
| `0` | 正常退出 |
| 文字 | 输出输入错误并以非零状态退出 |

## 填空/实现任务

1. 完成 `practice.c` 中的函数和菜单分支；
2. 为每个函数写清楚输入、输出和副作用；
3. 使用一次合法选项和一次未知选项测试；
4. 测试总和的 `n = 0`、`n = 1` 和普通值；
5. 测试文字输入，确认程序不会继续使用无效选项；
6. 记录每次输入、输出和返回状态。

## 自测题

1. 为什么菜单循环适合使用 `do while`？
2. `switch` 中的 `break` 负责什么？
3. 为什么把每个菜单功能拆成函数？
4. 输入失败时为什么不能继续执行原来的 `choice`？
5. 菜单项目如何体现参数、返回值和作用域？

## 验收标准

- [ ] 菜单至少显示一次；
- [ ] 合法选项能执行对应功能；
- [ ] 未知选项不会导致程序崩溃或错误退出；
- [ ] `0` 能正常退出；
- [ ] 非整数输入会被识别并返回非零状态；
- [ ] 主要功能已经拆成职责清晰的函数。
