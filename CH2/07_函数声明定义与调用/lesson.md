# 第 7 课：函数声明、定义与调用

## 本课目标

完成本课后，你应该能够：

- 区分函数声明、函数定义和函数调用；
- 理解函数原型为什么要出现在调用之前；
- 写出带返回类型和参数列表的函数；
- 识别“编译通过但链接失败”和“声明/定义不一致”的区别。

## 1. 三个动作

函数声明告诉编译器函数的接口：

```c
int double_value(int value);
```

函数定义提供函数体：

```c
int double_value(int value)
{
    return value * 2;
}
```

函数调用请求执行它：

```c
int result = double_value(21);
```

声明末尾有分号，定义后面是花括号。声明中的返回类型、函数名和参数类型应与定义一致。

## 2. 为什么需要声明

编译器按源文件从上到下处理。如果在调用点之前没有看到函数声明，编译器就无法可靠检查调用参数和返回类型。把声明放在调用前，可以让拼写错误和类型不匹配尽早暴露。

本课先把声明写在同一个 `.c` 文件中；下一章学习多文件项目时，会把公共声明移动到 `.h` 文件。

## 3. 定义和链接

一个函数通常需要恰好一个实现定义。只有声明没有定义，编译可能通过，但链接时可能出现“找不到函数实现”；同名函数定义多次则可能出现重复定义。

## 填空任务

1. 修改函数名、参数名和计算规则，但保持声明与定义一致；
2. 在 `main` 中调用函数两次；
3. 故意让声明和定义的参数类型不一致，记录编译器诊断后恢复；
4. 暂时删除函数定义，观察链接阶段错误；
5. 说明一次调用从声明、定义到执行的关系。

## 自测题

1. 函数声明和函数定义分别解决什么问题？
2. 为什么函数声明通常以分号结束？
3. 只有声明没有定义时，可能在哪个阶段失败？
4. 函数调用和函数定义有什么区别？
5. 声明和定义不一致可能造成什么风险？
