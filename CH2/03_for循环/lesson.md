# 第 3 课：`for` 循环

## 本课目标

完成本课后，你应该能够：

- 解释 `for` 的初始化、条件和更新三个部分；
- 编写固定次数和指定范围的循环；
- 识别常见的起点、终点和步长错误；
- 在循环中维护一个累加结果。

## 1. `for` 的执行顺序

```c
for (初始化; 条件; 更新) {
    /* 循环体 */
}
```

执行顺序是：

1. 执行一次初始化；
2. 判断条件；
3. 条件为真时执行循环体；
4. 执行更新；
5. 回到第 2 步。

条件第一次就是假时，循环体一次也不会执行。C17 中可以在 `for` 初始化部分声明循环变量，例如 `for (int i = 0; ... )`，它的作用域通常只在这个循环中。

## 2. 边界和累加

`i < count` 表示执行 `count` 次（若从 `0` 开始），`i <= n` 表示包含 `n` 这个终点。两者不能凭习惯替换。

累加时先设置初值：

```c
int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i;
}
```

如果忘记更新变量，可能产生无限循环；如果更新方向和条件不匹配，也会产生类似问题。

## 填空任务

1. 修改 `n`，先手算 `1 + 2 + ... + n`；
2. 将循环改成输出每个数字；
3. 分别测试 `n = 0`、`n = 1` 和一个较大值；
4. 把 `i <= n` 改成 `i < n`，说明少了哪个边界；
5. 尝试从 `n` 倒数到 `1`，保持循环最终能够结束。
