# 第 14 课：README 编写

## 学习目标

为一个多文件 C 项目写出别人可以照做的构建、运行、测试和限制说明。

## 核心概念

- README 首先要让读者知道项目做什么。
- 构建命令应能在干净环境中复制执行。
- 运行示例要写清输入、输出和参数。
- 已知限制、错误码和未实现功能要明确写出。

## 完整示例

先阅读并运行下面的完整示例，再打开同目录的练习文件。多文件课程请按照文档列出的编译命令一起编译。

```c
# Mini Stats

## 功能

读取一组整数并输出总和。

## 构建

gcc -std=c17 -Wall -Wextra -Wconversion -pedantic \
    src/main.c src/stats.c -Iinclude -o mini_stats

## 运行

./mini_stats

## 限制

当前版本不读取文件，也不处理超过 int 范围的输入。
```

## 练习任务

1. 为 CH8 第 10 或第 11 课项目写 README。
2. 必须包含功能、目录、构建、运行、测试和限制六部分。
3. 让另一位同学只看 README 执行一次构建。
4. 根据实际失败信息修正 README，而不是凭感觉写命令。
