# 第 16 课：多文件项目与预处理验收

本课不额外提供脚本。请使用前面课程的多文件练习完成验收。

## 概念验收

1. 头文件应该放声明还是实现？
2. 为什么需要头文件保护宏？
3. `#include` 发生在编译流程的哪个阶段？
4. 文件作用域 `static` 如何改变符号可见性？
5. `extern` 声明和真正定义有什么区别？
6. `gcc -c` 生成什么文件？
7. 链接器如何处理跨文件函数调用？
8. 修改头文件时，为什么多个源文件可能都要重新编译？
9. Makefile 的依赖列表有什么作用？
10. README 至少应该让读者知道哪些命令？

## 操作验收

在 CH8 第 10、11 或第 15 课目录中：

```sh
gcc -std=c17 -Wall -Wextra -Wconversion -pedantic -c *.c
gcc *.o -o app
./app
```

然后：

- 删除一个目标文件再重新链接，记录错误；
- 修改一个头文件再运行构建；
- 用预处理输出观察 `#include` 和条件编译结果；
- 检查内部 `static` 符号没有暴露为公共接口。
