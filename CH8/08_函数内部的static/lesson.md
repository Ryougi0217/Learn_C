# 第 8 课：函数内部的 static

## 学习目标

理解函数内部静态变量只初始化一次，但生命周期持续到程序结束。

## 核心概念

- 普通局部变量每次进入函数都会重新创建。
- 函数内部 `static` 变量只初始化一次。
- 它具有块作用域，但具有静态存储期。
- 使用时要明确隐藏状态会影响测试和线程安全。

## 完整示例

先阅读并运行下面的完整示例，再打开同目录的练习文件。多文件课程请按照文档列出的编译命令一起编译。

```c
#include <stdio.h>

static int next_id(void)
{
    static int current = 100;
    return current++;
}

int main(void)
{
    printf("%d\n", next_id());
    printf("%d\n", next_id());
    printf("%d\n", next_id());
    return 0;
}
```

## 练习任务

1. 在 `practice.c` 中写一个每次调用返回下一个编号的函数。
2. 解释为什么 `current` 不会在下一次调用时回到初值。
3. 增加一个重置函数，讨论它对封装的影响。
4. 说明为什么有隐藏状态的函数不如纯函数容易测试。
