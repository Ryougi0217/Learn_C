# 第 20 课：基础数据结构与算法验收

本课不额外提供脚本。请使用本章前面的练习和自己的测试完成验收。

## 概念验收

1. 线性查找和二分查找分别需要什么前提？
2. 冒泡、选择、插入排序的核心不变量是什么？
3. `qsort` 比较函数为什么不能直接返回两个整数之差？
4. 动态数组中的 `count` 和 `capacity` 分别表示什么？
5. 链表节点为什么不要求连续存储？
6. 为什么修改链表头指针时常需要二级指针？
7. 栈和队列的取出顺序分别是什么？
8. 递归函数的基线和递归步是什么？
9. DFS 和 BFS 分别使用什么访问策略？
10. 数据结构的所有权和销毁函数应该如何约定？

## 代码验收

- [ ] 手写过线性查找和二分查找。
- [ ] 手写过三种基础排序，并测试空数组和重复值。
- [ ] 手写过 qsort 比较函数。
- [ ] 手写过动态数组的追加和销毁。
- [ ] 手写过链表插入、查找、删除和销毁。
- [ ] 手写过栈和队列。
- [ ] 写过 DFS 或 BFS。
- [ ] 为每个项目列出了所有权和失败路径。

## 推荐命令

```sh
gcc -std=c17 -Wall -Wextra -Wconversion -pedantic practice.c -o practice
./practice
```

验收时不要只看排序后的输出；要检查函数在空输入、单元素和找不到目标时是否仍满足接口约定。
