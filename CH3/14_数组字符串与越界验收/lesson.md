# 第 14 课：数组、字符串与越界验收

本课不新增脚本。请使用 CH3 前 13 课的练习文件，完成一次从数组访问到文本分析的综合验收。

## 任务 A：数组

使用第 1～4 课：

- [ ] 能声明并遍历一维数组；
- [ ] 能用嵌套循环遍历二维数组；
- [ ] 能区分行数、列数、元素数量和字节数；
- [ ] 能复现并修复一次数组下标越界；
- [ ] 能说明 `sizeof(array)` 在数组当前作用域中的含义。

## 任务 B：字符数组和字符串

使用第 5、6 课：

- [ ] 能区分字符常量、字符串字面量和字符数组；
- [ ] 能说明 `\0` 的作用；
- [ ] 能计算可见字符数和保存空间；
- [ ] 能解释没有 `\0` 时使用 `%s` 的风险。

## 任务 C：库函数和输入

使用第 7～10 课：

- [ ] 能使用 `strlen`、`strcmp` 和 `strcpy`；
- [ ] 能完成 `memcpy`、`memcmp` 和 `memset` 调用；
- [ ] 能使用 `fgets` 并检查返回值；
- [ ] 能移除输入末尾的 `\n` 或 `\r`；
- [ ] 能说明字符串函数和内存函数的区别。

## 任务 D：手动实现和容量

使用第 11、12 课：

- [ ] 能手动实现长度、复制和反转；
- [ ] 能在写入前检查目标容量；
- [ ] 能为新增字符和结尾 `\0` 留出空间；
- [ ] 能解释截断和越界的差别。

## 任务 E：文本分析项目

使用第 13 课：

- [ ] 能完成空行、普通句子、连续空白和混合字符测试；
- [ ] 能记录每次输入、输出和返回状态；
- [ ] 能说明项目只处理固定容量和 ASCII 文本；
- [ ] 能指出每个函数的输入、处理和输出；
- [ ] 能用 Sanitizer 复查数组边界。

## 推荐验收命令

对越界课：

```text
gcc -std=c17 -Wall -Wextra -pedantic -g -O0 -fsanitize=address,undefined practice.c -o practice_san
./practice_san
```

对文本分析项目：

```text
gcc -std=c17 -Wall -Wextra -Wconversion -pedantic practice.c -o text_tool
printf 'C has 3 arrays\n' | ./text_tool
```

## 最终问答

请不看目录，独立回答：

1. 为什么数组下标从 0 开始？
2. 为什么长度为 `n` 的数组不能访问下标 `n`？
3. `sizeof` 得到的是数组长度还是字节数？
4. `strlen` 是否包含 `\0`？
5. `memcpy` 和 `strcpy` 的处理单位有什么区别？
6. `fgets` 为什么可能读入换行符？
7. 文本分析工具为什么需要 `in_word` 状态？
8. 如何判断一次字符串写入是否会越过数组容量？
