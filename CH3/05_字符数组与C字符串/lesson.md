# 第 5 课：字符数组与 C 字符串

## 本课目标

完成本课后，你应该能够：

- 声明字符数组并保存字符序列；
- 区分单个字符和字符串；
- 理解字符串字面量会初始化字符数组；
- 使用 `%c` 和 `%s` 选择匹配的输出方式。

## 1. 字符和字符数组

单个字符使用字符常量：

```c
char grade = 'A';
```

多个字符可以放进字符数组：

```c
char word[] = "hello";
```

`'A'` 是一个字符，`"hello"` 是一个字符串字面量。字符串字面量初始化数组时，会额外包含字符串结尾的 `\0`，下一课专门展开这个细节。

## 2. `%c` 和 `%s`

`printf` 中：

- `%c` 期待一个字符值；
- `%s` 期待一个以 `\0` 结尾的 C 字符串。

示例：

```c
char grade = 'A';
char name[] = "Ada";

printf("grade = %c\n", grade);
printf("name = %s\n", name);
```

不要把字符常量和字符串字面量混用。

## 3. 完整示例

```c
#include <stdio.h>

int main(void)
{
    char grade = 'A';
    char word[] = "Bootdev";
    char message[32] = "C arrays";

    printf("grade = %c\n", grade);
    printf("word = %s\n", word);
    printf("message = %s\n", message);

    for (size_t i = 0; word[i] != '\0'; i++) {
        printf("word[%zu] = %c\n", i, word[i]);
    }

    return 0;
}
```

循环遇到 `\0` 就停止，说明它正在把字符数组当作 C 字符串读取。
