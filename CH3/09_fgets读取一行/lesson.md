# 第 9 课：使用 `fgets` 读取一行

## 本课目标

完成本课后，你应该能够：

- 使用 `fgets` 从标准输入读取一行；
- 把字符数组容量传给输入函数；
- 检查 `fgets` 的返回值；
- 说明输入行可能包含结尾换行符。

## 1. `fgets` 的基本形式

`fgets` 的常见调用形式是：

```c
char line[64];

if (fgets(line, sizeof line, stdin) == NULL) {
    /* 输入结束或读取失败 */
}
```

它最多读取“容量减 1”个字符，并在成功时写入字符串结尾的 `\0`。如果用户按下回车且数组空间足够，换行符通常也会被保存。

## 2. 为什么要检查返回值

`fgets` 返回目标数组的地址；如果遇到输入结束或读取失败，会返回 `NULL`。不能只看数组里原来的内容来判断这次读取是否成功。

## 3. 完整示例

```c
#include <stdio.h>

int main(void)
{
    char line[64];

    printf("请输入一行文字：");
    if (fgets(line, sizeof line, stdin) == NULL) {
        fprintf(stderr, "没有读到输入。\n");
        return 1;
    }

    printf("原始输入：[%s]", line);
    return 0;
}
```

如果输入包含回车，方括号中的文本和后续输出可能出现在不同的行。下一课会专门移除这个换行符。

## 输入长度限制

如果一行文字超过数组容量，`fgets` 会先读取能放下的部分，并留下剩余字符在输入流中。本课先关注“安全地读取一部分”；完整清空长行会在后续输入练习中处理。
