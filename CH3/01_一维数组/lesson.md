# 第 1 课：一维数组

## 本课目标

完成本课后，你应该能够：

- 声明和初始化一维数组；
- 使用从 0 开始的下标访问元素；
- 使用循环遍历数组；
- 说明数组元素在内存中连续排列的基本特点。

## 1. 数组是什么

数组把多个相同类型的元素放在一个连续的对象中：

```c
int scores[4] = {88, 92, 76, 100};
```

这里有 4 个 `int` 元素，下标范围是 `0` 到 `3`：

- `scores[0]` 是 88；
- `scores[3]` 是 100；
- `scores[4]` 超出了数组范围，不能访问。

数组下标从 0 开始，是 C 初学者最常见的边界来源之一。

## 2. 遍历数组

通常用循环配合下标访问每个元素：

```c
for (size_t i = 0; i < 4; i++) {
    printf("scores[%zu] = %d\n", i, scores[i]);
}
```

循环条件 `i < 4` 表示访问 0、1、2、3，不会访问 4。

## 3. 完整示例

```c
#include <stdio.h>

int main(void)
{
    int scores[] = {88, 92, 76, 100};
    size_t count = sizeof scores / sizeof scores[0];

    for (size_t i = 0; i < count; i++) {
        printf("scores[%zu] = %d\n", i, scores[i]);
    }

    return 0;
}
```

`sizeof scores / sizeof scores[0]` 在数组仍处于当前作用域中的情况下，可以计算元素数量。
