# 第 3 课：数组下标与边界

## 本课目标

完成本课后，你应该能够：

- 根据数组长度写出合法下标范围；
- 识别 `i < length` 和 `i <= length` 的差别；
- 使用 Sanitizer 观察一次数组越界；
- 修复越界后重新验证程序。

## 1. 合法下标范围

如果数组有 `length` 个元素，那么合法下标是：

```
0 <= index < length
```

例如长度为 4 的数组，合法下标为 0、1、2、3。`length` 本身不是合法下标。

## 2. 越界为什么危险

C 通常不会自动为每次数组访问做边界检查。越界访问可能：

- 读到不属于数组的数据；
- 覆盖其他对象；
- 让程序输出不稳定；
- 在某些运行中看起来“没问题”，但仍然属于未定义行为。

因此“这次运行没有崩溃”不能证明下标正确。

## 3. 完整示例

下面的正确版本只访问合法元素：

```c
#include <stdio.h>

int main(void)
{
    int values[] = {10, 20, 30, 40};
    size_t length = sizeof values / sizeof values[0];

    for (size_t i = 0; i < length; i++) {
        printf("values[%zu] = %d\n", i, values[i]);
    }

    return 0;
}
```

## 4. 练习脚本的实验

练习脚本故意把第一条循环写成 `i <= length`。请先使用 Sanitizer 构建：

```text
gcc -std=c17 -Wall -Wextra -pedantic -g -O0 -fsanitize=address,undefined practice.c -o practice_san
./practice_san
```

观察报告指出的访问行号，然后把条件修复为 `i < length`。不要用“换一个数组大小”来掩盖边界错误。
