# 第 10 课：处理输入末尾换行符

## 本课目标

- 手动扫描字符数组并找到换行符；
- 用 `\0` 替换换行符，让字符串更适合后续处理；
- 兼顾 Unix 换行 `\n` 和 Windows 常见的 `\r\n`。

## 1. 手动移除换行符

读取成功后，可以从头扫描到字符串结尾：

```c
void trim_newline(char *text)
{
    size_t i = 0;

    while (text[i] != '\0') {
        if (text[i] == '\n' || text[i] == '\r') {
            text[i] = '\0';
            return;
        }
        i++;
    }
}
```

遇到第一个换行相关字符时，把它改成字符串结尾标记，后面的内容就不会被当成当前字符串的一部分。

## 2. 完整示例

```c
#include <stdio.h>

void trim_newline(char *text)
{
    size_t i = 0;

    while (text[i] != '\0') {
        if (text[i] == '\n' || text[i] == '\r') {
            text[i] = '\0';
            return;
        }
        i++;
    }
}

int main(void)
{
    char line[64];

    printf("请输入一行文字：");
    if (fgets(line, sizeof line, stdin) == NULL) {
        return 1;
    }

    trim_newline(line);
    printf("清理后：[%s]\n", line);
    return 0;
}
```

这里的函数只处理已经成功读入的字符串，不负责清空超长输入留下的剩余字符。

## 3. 空行和超长行

用户直接按回车时，数组中可能只有换行符和 `\0`。清理后得到的是空字符串。

如果输入超过数组容量，当前缓冲区可能没有换行符。此时清理函数不会报错，但剩余字符仍在输入流中。要处理完整长行，需要进一步循环读取。
