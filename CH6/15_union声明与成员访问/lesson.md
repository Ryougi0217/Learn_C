# 第 15 课：联合体 union 的声明与成员访问

## 学习目标

学习联合体的声明方式，并观察同一个联合体变量可以使用不同成员解释数据。

## 核心概念

- 联合体的所有成员共享同一块存储空间。
- 任意时刻通常只有最近写入的成员具有当前语义。
- 联合体使用点运算符访问成员。
- 读取未被写入或不匹配的成员可能涉及实现定义或未定义行为，不能随意当作类型转换。

## 完整示例

先阅读并运行下面的完整示例，再打开同目录的 `practice.c` 手写关键部分。

```c
#include <stdio.h>

union Number
{
    int integer;
    float decimal;
};

int main(void)
{
    union Number value = {.integer = 42};

    printf("integer = %d\n", value.integer);

    value.decimal = 3.5f;
    printf("decimal = %.1f\n", value.decimal);

    return 0;
}
```

## 练习任务

1. 声明一个包含整数和浮点数的联合体。
2. 依次写入两个成员并打印各自结果。
3. 解释为什么写入第二个成员后不能继续把第一个成员当作原值。
4. 与结构体比较：结构体成员是否共享存储空间？
