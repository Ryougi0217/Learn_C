## 编译命令

```sh
gcc -std=c17 -Wall -Wextra -Wconversion -pedantic practice.c -o practice
./practice
```

结构体数组本章先使用固定容量；动态扩展放在 CH5 和后续综合项目中。联合体部分重点关注共享存储和当前有效成员，不要把它当作普通结构体使用。
