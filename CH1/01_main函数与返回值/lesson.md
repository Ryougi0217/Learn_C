# 第 1 课：`main` 函数与返回值

## 本课目标

完成本课后，你应该能够：

- 识别 C 程序的入口函数；
- 解释 `int main(void)` 中的返回类型和参数列表；
- 使用返回值表达程序成功或失败；
- 在终端中查看程序退出状态。

## 1. 程序从哪里开始

最常见的无参数入口写法是：

```c
int main(void)
{
    /* 程序从这里开始执行 */
    return 0;
}
```

`int` 表示函数返回一个整数，`void` 表示这个版本不接收命令行参数。`main` 返回后，控制权回到操作系统，返回值会成为进程的退出状态。

约定上：

- 返回 `0` 通常表示成功；
- 返回非零值通常表示失败或某种异常情况；
- 返回值是给调用者/操作系统看的，不是自动打印到终端的文字。

## 2. 返回值和输出不是一回事

`printf`/`puts` 产生终端输出；`return` 结束函数并交回一个整数。一个程序可以“打印成功”却返回失败，也可以没有输出但返回 `0`。因此验收时要同时观察输出和退出状态。

在 Bash/WSL 中，运行程序后可以使用当前 shell 的退出状态查询语法；在 PowerShell 中可以查看 `$LASTEXITCODE`。不同终端读取退出状态的变量不同，但它们观察的是同一个概念：程序结束时交回的状态码。
