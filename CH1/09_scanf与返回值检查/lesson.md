# 第 9 课：`scanf` 与返回值检查

## 本课目标

完成本课后，你应该能够：

- 使用地址运算符把变量地址传给 `scanf`；
- 解释 `scanf` 返回值表示什么；
- 区分输入成功、格式不匹配和输入结束；
- 不把未成功赋值的变量当成有效输入继续使用。

## 1. `scanf` 如何写入变量

`scanf` 需要把读到的值写入变量，所以对普通标量变量要传地址：

```c
int age;
int matched = scanf("%d", &age);
```

`&age` 是变量 `age` 的地址。没有 `&` 时，传入的是未初始化的值或错误类型，可能导致严重问题。字符串数组的传入规则不同，后续学习字符串输入时再单独处理。

## 2. 返回值是成功赋值的数量

`scanf` 返回成功赋值的字段数；如果在任何转换前遇到输入结束，通常返回 `EOF`。例如：

```c
int left;
int right;
int matched = scanf("%d %d", &left, &right);

if (matched == 2) {
    /* 两个整数都已成功写入 */
}
```

如果用户输入 `12 hello`，第一个整数可能成功、第二个转换失败，此时返回值可能是 `1`，不能把它当作两个有效整数。检查返回值比只检查变量内容更可靠。

## 3. 本课边界

`scanf` 遇到不匹配的文本后，错误字符可能仍留在输入流中。复杂的重试和清理策略会在循环课程中继续学习。本课只要求：检查返回值；失败时报告失败；不要使用未确认有效的变量。
