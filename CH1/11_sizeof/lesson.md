# 第 11 课：`sizeof`

## 本课目标

完成本课后，你应该能够：

- 把 `sizeof` 当作 C 的运算符使用；
- 用 `%zu` 打印 `sizeof` 的结果；
- 计算数组拥有多少个元素；
- 说明大小结果来自当前编译器和平台，而不是凭感觉猜测。

## 1. `sizeof` 的基本用法

`sizeof` 可以作用于类型或表达式：

```c
sizeof(int)       // 类型写在括号中
sizeof score      // 表达式可以不写括号
sizeof(score)     // 写括号也可以
```

它的结果类型是 `size_t`，表示对象或类型占用的字节数。因此用 `printf` 输出时应使用 `%zu`。

`sizeof(char)` 按 C 语言定义为 1，但一个字节包含多少位由实现决定。其他类型的大小和对齐方式可能因平台不同而变化。

## 2. 数组元素个数

对于当前作用域中的数组，可以使用：

```c
int values[5];
size_t count = sizeof values / sizeof values[0];
```

分子是整个数组的字节数，分母是一个元素的字节数，相除得到元素个数。这个写法依赖 `values` 此时确实是数组；数组作为函数参数传递时会有不同规则，后续指针课程会专门解释。

## 3. 大小不是数值范围

`sizeof` 告诉你占用多少字节，不直接告诉你类型的所有取值范围。需要范围时使用相应的标准库宏；需要固定宽度时使用对应的固定宽度类型。
