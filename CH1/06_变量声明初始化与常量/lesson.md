# 第 6 课：变量声明、初始化与常量

## 本课目标

完成本课后，你应该能够：

- 区分变量声明、初始化、赋值和读取；
- 知道局部变量在使用前必须先写入确定值；
- 使用 `const` 表达不应被重新赋值的对象；
- 解释宏常量和 `const` 变量的基本差别。

## 1. 声明、初始化、赋值

```c
int score;       // 声明：告诉编译器类型和名字
score = 80;      // 赋值：写入一个值
int level = 2;   // 声明并初始化
level = 3;       // 后续再次赋值
```

声明不一定产生初始值。函数内部的自动存储期局部变量如果没有初始化，里面的值是不确定的；在写入确定值之前读取它是错误的使用方式。养成“声明时初始化”或“声明后立即赋值”的习惯。

## 2. 变量的类型和可修改性

变量的类型决定如何解释它占用的存储空间以及允许哪些运算。赋值时，右侧表达式会转换到左侧类型；转换可能带来截断或精度变化，后续课程会专门练习。

`const` 可以限制通过当前名字修改对象：

```c
const int max_score = 100;
/* max_score = 120; */  // 取消注释后会产生编译错误
```

`const` 不是“值一定在编译期替换”的宏，它仍然是一个有类型的对象。宏常量则由预处理器进行文本替换：

```c
#define PASS_SCORE 60
const int full_score = 100;
```

两者各有用途。本课先优先使用有类型、作用范围清晰的 `const`。

## 3. 命名和初始化习惯

变量名应体现含义，例如 `total_score` 比 `x` 更容易检查。初始化值要和变量类型匹配；整数常量、浮点常量和字符常量不要只靠视觉判断。
