# 第 4 课：浮点类型

## 本课目标

完成本课后，你应该能够：

- 区分 `float`、`double` 和 `long double` 的基本用途；
- 用精度说明符控制浮点输出；
- 解释浮点数是近似表示，而不是任意十进制小数的精确存储；
- 识别金额计算中直接使用浮点数的风险。

## 1. 浮点类型

C 常见浮点类型：

- `float`：占用空间较小，精度相对低；
- `double`：日常计算中更常用；
- `long double`：实现提供的更高精度类型，具体能力依平台而定。

给浮点常量加 `f` 后缀可明确写成 `float`，例如 `1.5f`；不加后缀的 `1.5` 默认是 `double`。

调用可变参数函数 `printf` 时，`float` 会提升为 `double`，所以打印普通浮点表达式时常用 `%f`。`long double` 使用 `%Lf`。

## 2. 输出精度

`%.2f` 表示小数点后显示两位，`%.17f` 可以帮助观察 `double` 的更多有效位。显示时四舍五入，不代表变量内部真的只保存了两位小数。

例如：

```c
double value = 0.1 + 0.2;
printf("%.17f\n", value);
```

你可能看到它并不等于十进制直觉中的精确 `0.3`。这是二进制浮点表示的正常现象，不一定是编译器故障。

## 3. 金额和相等比较

金额、计数等需要精确表达的值，常可转换成“分”后用整数保存。对浮点结果做相等比较也要谨慎，通常需要设置可接受误差。具体误差策略取决于业务需求，本课先记住“不要默认认为浮点数可以精确表示所有十进制小数”。
