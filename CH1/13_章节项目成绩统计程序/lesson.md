# 第 13 课：章节项目——成绩统计程序

## 项目目标

编写一个命令行成绩统计程序，完成：

- 读取三门课程的整数成绩；
- 检查输入是否确实包含三个整数；
- 计算总分和平均分；
- 判断成绩是否在 `0～100` 的范围内；
- 输出清晰、可复核的结果。

本项目刻意限制为“三个成绩、无数组、无自定义函数、无循环”，目的是把本章的变量、输入、运算、比较、格式化输出和显式转换串起来。后续数组和函数课程会把它重构得更好。

## 1. 输入和输出约定

输入示例：

```text
请输入三门成绩（用空格分隔）：88 92 76
```

预期信息至少包括：

- 三门成绩；
- 总分；
- 保留两位小数的平均分；
- 输入合法性或失败原因。

程序不应在 `scanf` 返回值不是 `3` 时继续使用三个成绩变量。

## 2. 推荐实现顺序

1. 声明三个成绩变量；
2. 使用一次 `scanf` 读取三个整数；
3. 检查返回值；
4. 检查每个成绩是否在允许范围内；
5. 计算总分；
6. 使用显式转换计算平均分；
7. 用 `printf` 输出结果；
8. 分别测试正常输入、少一个数、输入文字、超出范围。

## 3. 评分建议

可以按以下维度自评：

| 维度 | 通过表现 |
| --- | --- |
| 输入检查 | 能拒绝非三个整数的输入 |
| 范围检查 | 能拒绝小于 0 或大于 100 的成绩 |
| 计算 | 总分正确，平均分没有整数除法截断 |
| 输出 | 格式说明符匹配，结果易读 |
| 验证 | 至少完成四类输入测试 |

## 填空/实现任务

打开 `practice.c`，按标记完成或改造：

1. 修改提示文字和测试数据说明；
2. 补全输入返回值检查；
3. 补全成绩范围检查；
4. 补全总分和平均分计算；
5. 设计清晰的输出；
6. 记录每类输入的实际输出和程序返回状态。

完成基础版后，可以尝试扩展为五门成绩，但暂时不要复制粘贴大量代码；先记录“为什么数组会更适合这个需求”，留到 CH3 实现。

## 自测题

1. 为什么成绩总分适合使用整数？
2. 平均分为什么需要显式类型转换？
3. 输入三个值时，`scanf` 返回值应该是多少才算成功？
4. 输入超出 `0～100` 时，是输入格式错误还是业务范围错误？
5. 如果把三个成绩直接写进一条很长的表达式，如何检查它是否容易出错？

## 验收标准

- [ ] 正常输入时输出正确总分和平均分；
- [ ] 非三个整数时不会继续使用无效成绩；
- [ ] 越界成绩会被拒绝；
- [ ] 平均分保留两位小数且没有整数除法截断；
- [ ] 至少完成正常、少值、文字、越界四类测试。
