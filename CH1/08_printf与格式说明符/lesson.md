# 第 8 课：`printf` 与格式说明符

## 本课目标

完成本课后，你应该能够：

- 让格式字符串和参数数量、类型相匹配；
- 使用常见整数、浮点、字符、字符串和大小格式；
- 使用宽度和精度控制输出样式；
- 通过编译器警告发现格式错误。

## 1. `printf` 的基本模型

`printf` 的第一个参数是格式字符串，后面的参数依次填入其中的转换说明符：

```c
printf("score = %d\n", score);
printf("%s scored %d points\n", name, score);
```

格式字符串中的普通文字会原样输出；`%d` 等以 `%` 开头的部分告诉 `printf` 如何解释后续参数。

## 2. 常用格式

| 参数类型 | 常见格式 |
| --- | --- |
| `int` | `%d` |
| `unsigned int` | `%u` |
| `long` | `%ld` |
| `long long` | `%lld` |
| `double` | `%f`、`%.2f` |
| `char` | `%c` |
| 字符串 | `%s` |
| `size_t` | `%zu` |
| 百分号本身 | `%%` |

格式说明符、参数数量和参数类型必须匹配。错误匹配可能先产生警告，运行时还可能出现错误输出或未定义行为。学习阶段应始终打开警告选项。

## 3. 宽度和精度

`%8d` 可以给整数设置最小字段宽度；`%-8d` 通常表示左对齐。`%.2f` 表示浮点数显示两位小数，`%.*f` 可以把精度作为额外的整数参数传入。先掌握固定精度，再尝试动态宽度。
