# 第 10 课：显式类型转换

## 本课目标

完成本课后，你应该能够：

- 区分隐式转换和显式转换；
- 修复整数除法导致的小数部分丢失；
- 理解浮点转整数时的截断；
- 知道强制转换不能自动消除溢出和范围风险。

## 1. 隐式转换

当表达式中的操作数类型不同，C 会按语言规则进行转换。例如把 `int` 赋给 `double` 通常会把整数转换成浮点数：

```c
int count = 3;
double value = count;  // 隐式转换
```

隐式转换有时很方便，但复杂表达式中可能不容易看出结果类型。

## 2. 显式转换

显式转换写成：

```c
double average = (double)total / count;
```

这里先把 `total` 转成 `double`，所以除法在浮点类型中进行。转换只影响这次表达式的结果，不会改变 `total` 变量本身。

如果把浮点数转成整数，小数部分会被截去：

```c
int whole = (int)3.99;  // 3
```

在转换前必须考虑数值是否超出目标类型范围。强制转换不是修复溢出的通用工具，也不会把错误的业务单位变成正确单位。

## 3. 转换的位置很重要

`(double)(total / count)` 和 `(double)total / count` 不等价：前者先做整数除法再转成浮点，后者让除法本身使用浮点规则。先写出每一步的类型，再判断结果。
