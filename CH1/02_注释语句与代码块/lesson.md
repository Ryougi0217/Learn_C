# 第 2 课：注释、语句与代码块

## 本课目标

完成本课后，你应该能够：

- 区分单行注释和多行注释；
- 判断一条简单语句在哪里结束；
- 识别由花括号组成的代码块；
- 通过最小修改定位分号、括号和注释造成的问题。

## 1. 注释

C 常见两种注释：

```c
// 这一行直到换行都是注释

/*
   这里可以写多行说明
*/
```

注释用于解释意图、暂时屏蔽一小段代码或记录待办事项。注释不会成为程序的运行逻辑；但注释写错位置仍可能把本来要执行的代码屏蔽掉。不要用大段注释掩盖无法理解的代码，应尽量让变量名和结构本身清楚。

## 2. 语句和分号

多数执行语句以分号结束：

```c
int score = 100;
printf("%d\n", score);
return 0;
```

分号不是每一行都必须有：`if`、`for`、函数定义等结构的语法另有规则。初学阶段看到 `expected ';'` 时，先检查报错行附近以及上一行是否少了分号。

## 3. 代码块

一对 `{ }` 组成一个代码块。函数体是代码块，条件和循环的复合语句也可以是代码块。代码块把多条语句组织成一个整体，并会影响局部变量的可见范围；变量作用域会在后续课程进一步系统学习。

## 填空任务

1. 在 `practice.c` 中分别添加单行和多行注释；
2. 修改两个变量的初始值，观察语句执行顺序；
3. 将嵌套代码块中的输出语句暂时注释，再恢复；
4. 故意删除一个分号，记录编译器指出的位置，然后恢复；
5. 解释外层输出和内层输出各属于哪个代码块。

## 自测题

1. `//` 和 `/* */` 的适用范围有什么区别？
2. 为什么一条赋值语句通常需要分号？
3. 函数体是不是一个代码块？
4. 删除分号后，编译器标记的位置一定就是根因所在的位置吗？
5. 注释会不会在运行时输出到终端？

## 验收标准

- [ ] 能写出两种合法注释；
- [ ] 能识别语句结束位置；
- [ ] 能说明代码块的组织作用；
- [ ] 能通过编译器信息修复一个缺失分号错误。
