# 第 7 课：算术、比较、逻辑与赋值运算符

## 本课目标

完成本课后，你应该能够：

- 使用基本算术运算符完成整数计算；
- 解释整数除法和取余；
- 使用比较运算符得到真假结果；
- 使用逻辑运算符组合条件；
- 区分赋值 `=` 和相等比较 `==`。

## 1. 算术运算

常见算术运算符：

| 运算符 | 含义 |
| --- | --- |
| `+`、`-`、`*` | 加、减、乘 |
| `/` | 除 |
| `%` | 整数取余 |

两个 `int` 相除时，结果仍是整数：

```c
int quotient = 17 / 5;   // 3
int remainder = 17 % 5;  // 2
```

需要小数结果时，至少让一侧参与浮点运算，或者使用显式类型转换。除数不能为零。

## 2. 比较和逻辑

比较运算符包括 `==`、`!=`、`<`、`<=`、`>`、`>=`。结果是整数真假值：零表示假，非零表示真；比较表达式本身通常产生 `0` 或 `1`。

逻辑运算符：

- `&&`：两边都为真；
- `||`：至少一边为真；
- `!`：把真假反转。

`&&` 和 `||` 有短路行为：如果左侧已经足以决定结果，右侧可能不会执行。因此右侧常用于放置安全前置条件，例如先检查指针不为空再访问它。

## 3. 赋值和复合赋值

`=` 是把右侧结果写入左侧对象，不是比较。常见复合赋值包括 `+=`、`-=`、`*=`、`/=` 和 `%=`：

```c
score += bonus;  // 等价于 score = score + bonus;
```

表达式的优先级存在，但不要过度依赖记忆；复杂表达式主动加括号，减少误读。
