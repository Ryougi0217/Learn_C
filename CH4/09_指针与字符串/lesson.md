# 第 9 课：指针与字符串

## 本课目标

完成本课后，你应该能够：

- 使用字符指针遍历 C 字符串；
- 通过解引用读取当前字符；
- 说明指针何时移动到下一个字符；
- 区分可修改字符数组和不应修改的字符串字面量。

## 1. 字符串指针

C 字符串仍然是以 `\0` 结尾的字符序列。字符指针可以指向它的第一个字符：

```c
char text[] = "hello";
char *cursor = text;
```

只要 `*cursor` 不是 `\0`，就可以读取当前字符，然后让 `cursor++` 指向下一个字符。

## 2. 完整示例

```c
#include <stdio.h>

int main(void)
{
    char text[] = "hello";
    char *cursor = text;
    size_t length = 0;

    while (*cursor != '\0') {
        printf("character = %c\n", *cursor);
        cursor++;
        length++;
    }

    printf("length = %zu\n", length);
    return 0;
}
```

这里的 `text` 是字符数组，可以修改：

```c
text[0] = 'H';
```

字符串字面量通常不应通过可写指针修改：

```c
const char *literal = "hello";
```

把字符串字面量当成可写数组修改会产生未定义行为。

## 指针和下标可以互换

对于字符数组，`text[i]` 和 `*(text + i)` 表达同一个字符。指针写法更适合练习“当前游标在哪里”，下标写法通常更直观地表达“第几个元素”。
