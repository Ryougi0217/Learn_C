# 第 1 课：地址与内存

## 本课目标

完成本课后，你应该能够：

- 区分变量保存的值和变量所在的地址；
- 使用取地址运算符 `&` 获得对象地址；
- 使用 `%p` 观察地址；
- 说明地址数值为什么不适合当成固定答案。

## 1. 对象和值

声明一个变量时，程序会为它对应的对象准备存储空间：

```c
int score = 95;
```

`score` 表达式表示其中保存的值；`&score` 表示这个对象在当前运行中的地址。可以把它想成：

```
对象：score
值：95
地址：某个运行时位置
```

地址由运行环境安排。重新运行程序、改变编译选项或改变系统，都可能让地址变化。

## 2. 打印地址

`printf` 使用 `%p` 打印指针表示的地址，通常把地址转换为 `void *`：

```c
printf("score = %d\n", score);
printf("address = %p\n", (void *) &score);
```

不要用 `%d` 打印地址，也不要假设地址一定是某个固定十六进制数。

## 3. 完整示例

```c
#include <stdio.h>

int main(void)
{
    int score = 95;

    printf("score = %d\n", score);
    printf("address = %p\n", (void *) &score);

    return 0;
}
```

同一轮运行中，`&score` 指向 `score` 对象；但具体数值只适合用来观察关系，不适合写死在程序中。
