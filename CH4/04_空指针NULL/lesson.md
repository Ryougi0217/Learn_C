# 第 4 课：空指针 `NULL`

## 本课目标

完成本课后，你应该能够：

- 说明 `NULL` 表示“当前没有指向可用对象”；
- 在解引用前检查指针是否为空；
- 区分空指针和未初始化指针；
- 避免把空指针传入需要有效对象的操作。

## 1. `NULL` 的意义

空指针是一个特殊的指针值：

```c
int *pointer = NULL;
```

它不指向可供你访问的 `int` 对象。下面的判断可以决定是否安全访问：

```c
if (pointer != NULL) {
    printf("%d\n", *pointer);
} else {
    printf("没有可访问的对象。\n");
}
```

不能因为 `NULL` 是一个常见写法，就对它解引用。

## 2. 空指针和未初始化指针

这两个状态不同：

- `int *pointer = NULL;`：指针有明确的“无目标”状态；
- `int *pointer;`：指针没有初始化，里面的位模式不应被当成地址使用。

初始化为空指针可以让函数明确表达“没有结果”或“暂时没有对象”。

## 3. 完整示例

```c
#include <stdio.h>

int main(void)
{
    int score = 95;
    int *pointer = NULL;

    if (pointer == NULL) {
        printf("pointer is empty\n");
    }

    pointer = &score;

    if (pointer != NULL) {
        printf("score through pointer = %d\n", *pointer);
    }

    return 0;
}
```

## 失败路径要可处理

函数接收指针参数时，应该明确它是否允许为空。如果允许，就在解引用前检查；如果不允许，就在接口说明中写清楚前置条件。
