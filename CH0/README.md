# CH0：环境与编译模型

本章目标是建立一条完整的 C 程序认知链：

```
源代码（.c/.h）
        ↓ 预处理、编译、汇编、链接
可执行文件
        ↓ 终端运行
程序输出或错误信息
```

每一课都放在独立文件夹中。课程 Markdown 同时承担讲解、完整示例、练习说明和自测题。

## 练习模式

本章采用“完整示例 + 关键挖空”的混合模式：

- `lesson.md` 中会先给出可以阅读的完整示例、命令和预期现象；
- 已经讲过的基础结构通常直接写好，让你把注意力放在本课的新概念上；
- 第一次遇到库函数、跨文件函数或内存 API 时，会把声明、调用、参数或释放位置留为 `TODO`；
- 编译错误与 Sanitizer 课程会保留故意的错误或越界，用来训练你读诊断报告；
- 项目课不会把每一行都挖空，而是留下需要你独立完成的核心逻辑；
- 脚本能否立即编译不是唯一标准，完成空位、读懂诊断、运行并验证才算完成。

不要直接把 `lesson.md` 的完整示例复制到练习文件。先根据提示手写，再编译、运行和记录结果。
